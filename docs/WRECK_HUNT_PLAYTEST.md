# WRECK HUNT — Rendered Playtest Notes

Last reviewed: 2026-09-07

## Test setup

- Production-equivalent `_site` output generated by `scripts/prepare-pages.py`
- Playwright Chromium with an iPhone-like 852×393 landscape viewport and touch/mobile flags
- Software WebGL on the CI runner; this is not a real iPhone Safari measurement

## Observed progression

The first pass exposed a major pacing problem: CPU cars were wrecking one another while the player could drive for many seconds without scoring. The post-fix rendered run changed that substantially: the player earned the first WRECK almost immediately after entering the fight and the HUNT SCORE rose from 0 to 1937 on that first scoring sequence.

The same run then exposed the opposite problem: too many CPU cars focused the player at once and HULL fell too quickly for a 150-second score attack.

## Final tuning goals

- Put a damaged opening bounty directly in the first driving lane so the WRECK loop is demonstrated immediately.
- Keep one explicit 3D TARGET marker instead of several overlapping objective markers.
- Give the player a strong finisher advantage while reducing CPU-vs-CPU damage.
- Split CPU aggression so the player gets pressure without every car piling onto the hunter.
- Restore 10% HULL on player-owned WRECKS to reward aggressive chaining.
- Extend the CHAIN window from 7 seconds to 9 seconds.
- Respawn replacement targets closer to the fight with inward momentum.
- Add light target steering assistance and stronger wall-edge recovery without taking away manual steering.
- Keep CPU wreck/respawn notices out of the center-screen message lane so player actions stay readable.
- Keep `HUNT SCORE`, WRECK count, CHAIN state, and impact messages in distinct HUD roles.

## Regression checks

`scripts/test-wreck-hunt.mjs` verifies the production-generated runtime, including the opening bounty, first-five-second WRECK loop, player-owned finisher scoring, HULL repair, nine-second CHAIN timing, respawn position/momentum, target/HUD integration, and a short finite-state combat soak.
